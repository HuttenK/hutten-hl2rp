# Medieval RP

Средневековая ветка сборки на Helix — `medieval`. SCP-версия развивается отдельно в `scp-schema`.

- Удалены электроника, терминалы, КПК, камеры, рации, энергетика, ключ-карты, современные служебные фракции и SCP-системы.
- Удалены ARC9 и его интеграции из самой сборки. **`ammo_cringe` сохранён**: инвентарное оружие, слоты, боезапас, сохранение состояния и перенос предметов.
- Удалены уровни, опыт, навыки, SPECIAL и их бонусы/проверки. Ремесло требует материалы, инструменты и рабочее место.
- Сохранены здоровье, ранения, волочение тел, переноска, сон, еда, ремесло, земледелие, добыча, торговля, обычные замки, записи и поручения.
- Стартовое меню, создание персонажа, TAB, кнопки, пиктограммы, вспомогательные окна, ранение и смерть получили средневековое оформление.

[Подробности и проверки](docs/medieval-cleanup/README.md) · [Лист оформления](art-direction/medieval-ui/style-preview.html) · [Ассеты для контента](addons/medieval_ui_content/README.md).

## Установка для проверки

1. Использовать **отдельную установку сервера и отдельные данные**. Техническое имя схемы пока остаётся `ixhl2rp`; общая база с SCP не предусмотрена.
2. Поместить полные каталоги `helix` и `ixhl2rp` из этой ветки в `garrysmod/gamemodes`. Нужна чистая копия каталогов: обычное слияние поверх SCP оставит удалённые плагины на диске.
3. Скопировать `addons/medieval_ui_content` в `garrysmod/addons` или добавить шесть PNG из его `materials` **прямо в корень `materials`** своего Workshop-контента medieval. Подпапка `medieval_ui` не нужна. При ручной установке файлов путь в игре — `garrysmod/materials/<имя>.png`.
4. Для текущих временных моделей оставить используемый SD-контент, библиотеки анимаций и общие зависимости сборки. Для оружия нужны **Age of Chivalry SWEPs & SENTs**, **wOS DynaBase** и **Animation Extension — Age of Chivalry** на сервере и у игроков. [Каталог предметов, зависимости и проверка анимаций](docs/medieval-weapons/README.md). Средневековые модели персонажей ещё предстоит подобрать.
5. Запустить схему `ixhl2rp` и пройти проверку из отчёта.

Внешняя Workshop-коллекция не меняется автоматически: оставшиеся в ней ARC9/SCP-аддоны будут загружаться независимо от гамемода. Для medieval нужна собственная подборка контента.

## Проверки исходников

```text
npm ci
npm test
node tools/audit.cjs
node tools/audit-medieval.cjs
```

Автотесты используют имитации API и не заменяют запуск сервера и проверку отрисовки в Garry’s Mod. Старые SCP-отчёты и инструменты в `docs`/`tools` сохранены как история; прежние SCP-скрипты развёртывания не предназначены для установки medieval.
