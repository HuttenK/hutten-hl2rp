# Вступление и финал

В medieval возвращены `z_intro` и `z_endingnotext` из ветки SCP. Исторический список `medieval-cleanup/removals.json` описывает первоначальную очистку, а не актуальное отсутствие этих двух плагинов.

- `/StartIntro` — запускает вступление для всех подключённых игроков. После слайдов окно закрывается и возвращает управление.
- `/StartEndingNoText` — запускает финал для всех, замораживает персонажей и сбрасывает их медицинское состояние, как в исходной версии. После слайдов предлагает отключиться по пробелу. Это завершение сессии, а не обычное закрываемое окно.

Обе команды доступны только администраторам; автоматического запуска при подключении нет. Отдельный плагин титров `z_ending` не возвращён. Шрифт вступления теперь объявляется внутри `z_intro`, поэтому зависимости от титров нет. Запоздалый ответ загрузки музыки после удаления панели останавливает звук.

Тексты, порядок слайдов, длительности и имена файлов сохранены из SCP-версии. Средневековый сюжет и новые иллюстрации в рамках восстановления не создавались. Медиа должны быть смонтированы у клиентов через контент:

| Ролик | Картинки относительно `materials/` | Музыка относительно `sound/` |
| --- | --- | --- |
| Intro | `pr_intro_slide1.png` — `pr_intro_slide4.png` | `pr_intro.mp3` |
| Ending | `ending_slide_1.png` — `ending_slide_5.png` | `legends_ending.mp3` |

Скрипты раздаются клиентам стандартным загрузчиком Helix, `derma/` подключается автоматически. Картинки и музыка не входят в эти четыре Lua-файла; восстановление плагинов не заменяет Workshop-контент.

Проверки: `node tools/test-medieval-cinematics.cjs` проверяет ограничения команд, сохранение прежнего поведения финала, загрузку без плагина титров, повторный запуск и освобождение звука/панелей. Это изолированные проверки Lua, не подтверждение воспроизведения в Garry’s Mod.
