# SCP snapshot — 2026-11-02

This release publishes the current local `helix`, `ixhl2rp` and companion addon
sources on `scp-schema`, continuing the existing SCP commit history. The original
`main` branch remains unchanged. The `medieval` branch starts from this release.

Changes accumulated since the previous GitHub SCP snapshot include:

- CCTV, bodycams and terminal-map improvements; persistence for physical devices
  and prop-mounted screens.
- Medical beds and wheelchairs, patient transport and voluntary wheelchair use.
- Clothing/model uniforms, character height and animation compatibility fixes.
- SD hair colour/content updates and compound area support.
- Power-source integration, blackout electronics and map-door access.
- Server/client workload reductions, bounded update work and performance capture
  tools; SQLite item-ID loading uses an aggregate instead of loading all IDs.
- ARC9 hitscan policy, shooting-effect fixes, arm update budgets and protection
  against CSS fallback models on equipped weapons.
- The fullscreen map is accessible through the terminal rather than standalone
  keyboard or console shortcuts.

Installation: merge `helix` and `ixhl2rp` into `garrysmod/gamemodes`, retain the
required Workshop collection and install/update companion addons as described in
their READMEs. Restart the server and reconnect clients. This is a full source
snapshot, not one of the earlier changed-files ZIP patches.

The medieval branch initially inherits SCP systems and dependencies. It is a
development starting point, not an already converted medieval gamemode.

Validation for publication covers normalized Lua syntax and targeted offline
regression suites. Those checks do not establish live multiplayer rendering,
engine compatibility for every addon combination, or measured FPS improvements.
Known third-party addon errors reported in logs are not silently treated as
resolved by publishing this snapshot.
