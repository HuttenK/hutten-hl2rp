# Черты персонажа — medieval

35 пассивных черт. Выбор находится на третьем этапе создания персонажа: происхождение → личность → **черты** → внешность → проверка. После создания список доступен в TAB → «Персонаж».

Начальный баланс — **0**. Недостатки дают очки, достоинства их расходуют. Остаток должен быть ≥ 0; тратить все очки необязательно. Можно создать персонажа без черт. Например: гениальность −3, слабое телосложение +2, заикание +1 = 0.

Сервер повторно проверяет баланс, идентификаторы, типы значений и несовместимость. Ступени одной группы не складываются: выбор новой заменяет старую. Достоинства и недостатки телосложения, интеллекта и красоты взаимоисключающие внутри соответствующей группы. Также несовместимы слабость/сила, тугодумие/сметливость и карликовость/гигантизм.

Речевые эффекты работают в IC, шёпоте и крике. OOC, LOOC, /me, /it, личные и служебные сообщения не изменяются. Тугодумие не преобразует собственные сообщения и не обрабатывает голосовой чат.

Тяжёлые классы: `aoc_flamberge`, `aoc_longsword`, `aoc_halberd`, `aoc_halberd_evil`, `aoc_doubleaxe`, `aoc_warhammer`, `aoc_longbow`. Меч со щитом и парные кинжалы разрешены: занятость обеих рук сама по себе не означает тяжёлое двуручное оружие. Ограничение действует при экипировке, выборе SWEP и попытке атаки.

«Сила» синхронно сокращает задержку следующей атаки, моменты трассировки удара и анимацию. Блокирование, доставание оружия и анимация ожидания сохраняют обычную скорость. Данные копируются на экземпляр оружия и пересчитываются только при изменении множителя. Файлы AoC/wOS/Workshop не редактируются.

## Травмы, ремесло и сохранение

- При физической травме головы тяжестью от 8 единиц: **2%** получить одноглазость, если её ещё нет. Проверка происходит после брони, один раз на нанесённую рану, а не повторно во внешнем вызове обработки брони. Ожоги, яд и удушье глаз не отнимают.
- Потеря ноги синхронизируется с чертой. Административное восстановление ноги удаляет её; повторный вход не ампутирует восстановленную ногу снова.
- Ремесло имеет базовую длительность **5 секунд** (или `recipe.time`, если задано). Материалы и инструменты повторно проверяются и расходуются только при завершении. Одновременно можно создавать один предмет. Смена персонажа, смерть, удаление/смена станции, уход дальше 128 единиц или начало другого действия отменяют изготовление. Прогресс виден на кнопке ремесла.
- Черты сохраняются в JSON-поле `ix_characters.traits` и синхронизируются штатными механизмами Helix. Существующие персонажи получают пустой набор; их черты автоматически не раздаются. Уже имеющаяся ампутация ноги отражается в списке после загрузки персонажа.
- Приобретённые травмы не открывают повторное редактирование набора или новые покупки за очки. Очки используются только при создании.
- Уровни и навыки не возвращаются. Новых активных способностей нет.

## Контент и проверка

35 иконок взяты с [CK3 Wiki — Traits](https://ck3.paradoxwikis.com/Traits). Пути источников, размеры и SHA-256: [character-trait-icons.json](character-trait-icons.json). Это графика Crusader Kings III / Paradox Interactive, а не новые авторские изображения проекта.

Для Workshop обновить `addons/medieval_ui_content`: все `ck3_trait_*.png` находятся непосредственно в `materials/`, рядом с шестью существующими фонами/рамками. Материалы не загружаются из интернета во время игры. Если контент не установлен, названия/описания и выбор остаются доступны без ERROR-текстур.

Проверки: `npm test`, `npm run audit`, `npm run audit:medieval`. Автотесты охватывают бюджет, ввод, взаимоисключения, здоровье, бинты, диапазоны роста, UTF-8-речь, оружие, приобретение травм, ремесло и PNG-контент. Это проверки Lua с моделированием окружения, не запуск GMod.

Остаётся живая проверка в GMod: вид этапа «Черты» на вашем разрешении, создание и перезаход, внешний вид низкого/высокого персонажа, оба ракурса ускоренных ударов AoC и речь с двумя клиентами. После обновления Lua нужна перезагрузка сервера/карты и переподключение клиентов.
