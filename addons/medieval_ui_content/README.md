# Medieval UI — контент v2

Этот каталог с `addon.json` можно использовать как корень Workshop-аддона. Для добавления в другой medieval-пак положить все шесть PNG **непосредственно в `materials`**, без дополнительной папки. При ручной установке — в `garrysmod/materials`. Шесть актуальных изображений:

| Файл в `materials/` | Назначение |
| --- | --- |
| `cloister_v2.png` | Читаемый каменный двор с арками справа, тёмная поверхность за меню слева |
| `panel_v2.png` | Потёртая латунная рамка с угловой гравировкой и чёрной фактурной серединой |
| `button_v2.png` | Отдельная горизонтальная кнопка с металлическими гранями |
| `slot_v2.png` | Объёмная рамка инвентарной ячейки |
| `slot_selected_v2.png` | Золотое выделение выбранной ячейки; также подсветка кнопок |
| `divider_v2.png` | Тонкий орнаментальный разделитель с прозрачностью |

Все шесть файлов сгенерированы встроенным imagegen по утверждённому концепту. Они реально подключены к игровому Lua-интерфейсу. Кнопки и панели масштабируются по девяти участкам: углы не растягиваются. Служебные действия и пустые слоты сохраняют векторные знаки; при отсутствующем контенте используются простые поверхности вместо ERROR-материалов.

Текст, выбранные предметы и персонаж в текстуры не запечены: их рисует игра. **Новые предметные иконки пока не добавлены по просьбе пользователя.** Инвентарные предметы используют прежние 3D-модели. Экспериментальный рисованный атлас сохранён вне аддона, в `art-direction/medieval-ui/deferred-item-icons`, и игрой не загружается. Музыка не добавлена; необязательный путь — `sound/medieval_ui/menu.mp3`.

Подключение: `ixhl2rp/plugins/zz_legends_interface/sh_plugin.lua`, `helix/gamemode/game/cl_legends_theme.lua`, `cl_medieval_icons.lua`. Старые две текстуры сохранены отдельно в `art-direction/medieval-ui/archive-v1`, в контент-паке они не нужны.

Пак предназначен для medieval. SCP-пак SD не изменён. После установки контента перезапустить клиент для перечитывания закэшированных материалов. Промпты, исходные файлы и статус проверки: `art-direction/medieval-ui/assets-v2.json` и `README.md` в том же каталоге.
