# Medieval — контент v5

Этот каталог с `addon.json` можно использовать как корень Workshop-аддона. Для добавления в другой medieval-пак положить все PNG **непосредственно в `materials`**, без дополнительной папки. При ручной установке — в `garrysmod/materials`. Шесть изображений оформления:

| Файл в `materials/` | Назначение |
| --- | --- |
| `hall_v3.png` | Единая тёмная стена со встроенной деревянной нишей, тканью и подставкой справа |
| `panel_v2.png` | Потёртая латунная рамка с угловой гравировкой и чёрной фактурной серединой |
| `button_v2.png` | Отдельная горизонтальная кнопка с металлическими гранями |
| `slot_v2.png` | Объёмная рамка инвентарной ячейки |
| `slot_selected_v2.png` | Золотое выделение выбранной ячейки; также подсветка кнопок |
| `divider_v2.png` | Тонкий орнаментальный разделитель с прозрачностью |

Также добавлены **35 иконок черт** `ck3_trait_*.png` с [CK3 Wiki — Traits](https://ck3.paradoxwikis.com/Traits), графика Crusader Kings III / Paradox Interactive. Итого в `materials` — 41 PNG. Иконки используются при создании персонажа; предметные иконки не заменяются. Источники и контрольные суммы перечислены в `docs/character-trait-icons.json` репозитория; описание черт — в `docs/character-traits.md`. Их наличие в паке не означает предоставления новой лицензии на исходную игровую графику.

Все шесть файлов сгенерированы встроенным imagegen. Новый фон выполнен по ориентиру Kingdom Come: ниша объединена со стеной в одном изображении, отдельная картинка поверх фона не используется. На широких экранах расширяется спокойная часть стены; пропорции ниши сохраняются. Кнопки и панели масштабируются по девяти участкам: углы не растягиваются. Служебные действия и пустые слоты сохраняют векторные знаки; при отсутствующем контенте используются простые поверхности вместо ERROR-материалов.

Текст, выбранные предметы и персонаж в текстуры не запечены: их рисует игра. **Новые предметные иконки пока не добавлены по просьбе пользователя.** Инвентарные предметы используют прежние 3D-модели. Экспериментальный рисованный атлас сохранён вне аддона, в `art-direction/medieval-ui/deferred-item-icons`, и игрой не загружается. Музыка не добавлена; необязательный путь — `sound/medieval_ui/menu.mp3`.

Подключение: `ixhl2rp/plugins/zz_legends_interface/sh_plugin.lua`, `helix/gamemode/game/cl_legends_theme.lua`, `cl_medieval_icons.lua`. Старые текстуры сохранены отдельно в `art-direction/medieval-ui/archive-v1` и `archive-v2`, в контент-паке они не нужны. `cloister_v2.png` больше не загружается. При обновлении нужны новый `materials/hall_v3.png` и Lua-изменения обеих папок gamemode; прежние пять рамок остаются.

## Крики при ударах

Четыре записи пользователя добавлены в `sound/medieval/combat/scream_1.wav` — `scream_4.wav`. Формат: WAV PCM 16 бит, моно, 44,1 кГц. Обработка ограничена сведением стерео в моно и преобразованием частоты/формата; оригиналы MP3 сохранены без изменений. Общий размер — около 374 КиБ. Контрольные суммы и длительности — `docs/medieval-weapons/attack-cries.json` в репозитории.

При каждом начавшемся ударе AoC сервер выбирает одну запись и воспроизводит её для атакующего и окружающих. Отказ из-за нехватки стамины или незавершённого предыдущего замаха не вызывает крик. Отдельный голосовой канал не даёт крикам одного персонажа наслаиваться друг на друга и не заменяет звуки оружия.

Для Workshop обновить весь этот каталог, включая новую папку **`sound` рядом с `materials`**. Для ручной установки скопировать `sound/medieval` в `garrysmod/sound/medieval` на сервере и клиенте. Lua регистрирует все четыре WAV для скачивания; серверу также нужны сами файлы. На локальном клиенте они устанавливаются вместе с изменениями.

Пак предназначен для medieval. SCP-пак SD не изменён. После установки контента перезапустить клиент для перечитывания закэшированных материалов. Промпты, исходные файлы и статус проверки: `art-direction/medieval-ui/assets-v3.json`, `assets-v2.json` и `README.md` в том же каталоге. Совмещение модели с подставкой проверено расчётами; живая проверка в GMod ещё требуется. Для криков проверены декодирование и логика вызовов; пространственное звучание в игре нужно проверить отдельно.
