# FIELDLINK UI sounds

Seven original synthesized electronic cues: hover, click, boot, sleep, success, error and registration. Generated by `tools/build-pda-sounds.cjs`, without external samples or recordings. No additional third-party sound license is required for these generated cues.

Format: 44.1 kHz, mono, 16-bit PCM WAV. Short attack/release envelopes avoid clicks; restrained output levels suit repeated UI use. Playback is throttled in `site_pda/cl_sounds.lua`. Registration is a quiet physical device sound; other UI feedback plays locally.
