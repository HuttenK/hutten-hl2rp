# Medieval UI v2 — ближе к утверждённому концепту

Утверждённый ориентир: `../ui-concepts/2026-11-02/b-ash-and-iron.png` (оригинал сохранён). Версия v2 исправляет чрезмерно простое оформление первого варианта: вместо плоских линий используются отдельные художественные текстуры рамок, кнопок, ячеек и знаков.

- Каменный двор виден за персонажем; слева фон спокойнее для чтения текста.
- Орнаментальные углы, состаренные латунные грани, тёмные фактурные поверхности.
- Золотое выделение выбранных ячеек и активных кнопок.
- Служебные пиктограммы и символы пустых слотов остаются векторными. Новые предметные иконки отложены по просьбе пользователя; пробный атлас хранится в `deferred-item-icons` и не входит в активный контент.
- TAB: колонки инвентаря / описания / живой модели, крупное превью предмета, показатели справа внизу. Размеры самих инвентарей не изменяются.
- Та же тема применяется к старту, созданию персонажа, подсказкам, действиям, подтверждениям, ранениям и экрану смерти.

`style-preview.html` и `*-v2.png` — **браузерная проверка фактических ассетов**, не снимки игры. Предметные картинки и область персонажа оставлены пустыми намеренно. В GMod показываются прежние модели предметов, их данные и модель игрока. HTML не загружается в игровой интерфейс: там используется нативный Derma.

`node tools/build-medieval-style-preview.cjs` пересобирает лист проверки из Lua-таблицы служебных знаков и изображений контент-пака. Проверены его пять страниц и выделение ячейки, 14 изолированных Lua-наборов и синтаксис 990 Lua-файлов. **Запуска GMod в этой проверке не было**: реальное кадрирование 3D-модели и расположение вложенных панелей остаются игровым этапом проверки.

Контент для Workshop находится в `../../addons/medieval_ui_content`. Шесть актуальных изображений и их промпты перечислены в `assets-v2.json`; отложенный атлас отмечен отдельно. Первые две текстуры сохранены в `archive-v1`; исходные генерации также оставлены на месте.
